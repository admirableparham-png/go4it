# Outreach — Iranian ceramic/porcelain tiles (+ bricks) → Georgia

**Positioning:** Iran already leads Georgia's budget/mid porcelain **volume** segment on price/m².
Lead with a *delivered price per m²*, make it effortless (we handle logistics, customs, docs), and
be transparent that 18% VAT + ~5% duty are the buyer's account so they see true landed cost.

**Send etiquette:** most buyers read Georgian or Russian. Send English + offer to continue in
Georgian/Russian, or translate before sending. Attach a 1-page price list + a few product photos.
Keep the first email short; the goal is a reply + a sample request.
